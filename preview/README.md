# 개발 버전 배포

- 기존 사용자용 앱 파일은 변경하지 않습니다. 개발 파일만 이 폴더에 분리했습니다.
- `/preview/`에서 검증된 동현 Google 계정으로 로그인하면 `/preview/app.html`의 현재 로컬 버전을 엽니다.
- 다른 계정에서는 개발 UI 스크립트를 실행하지 않습니다. GitHub Pages의 정적 파일과 저장소 소스 자체를 비공개로 만드는 기능은 아닙니다.
- 이 미리보기는 서비스 워커를 등록하지 않고 알림 서버도 연결하지 않습니다. 기존 사이트의 캐시, 구독, 역할별 표시 버전 설정은 변경하지 않습니다.
- 자동 커뮤니티 개인정보 마이그레이션을 미리보기에서 실행하지 않습니다.
- 이번 배포 커밋에는 `[skip update notification]` 표시를 붙입니다. 알림 워크플로는 이 표시를 검사하고, 향후 `preview/**`만 변경한 푸시도 제외합니다.
- Firebase 운영 규칙은 이번 Git 배포에서 변경하지 않습니다. 새 선택지 첨부 저장에는 로컬 작업본의 확장된 `firestore.rules` 운영 반영이 별도로 필요합니다.
- 기능 테스트는 사용자 요청에 따라 사용자가 진행합니다.
