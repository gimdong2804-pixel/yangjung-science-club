# 폰을 대용량 영상 서버로 만드는 방법

## 먼저 알아둘 것

이 폴더는 100MB보다 큰 MP4/WebM 영상을 안 쓰는 폰과 USB에 저장하기 위한 서버입니다.

- 100MB 이하 영상: 기존 Cloudinary 무료 저장소
- 100MB 초과~1GB 이하 영상: 폰 + USB 저장소
- 폰 서버가 꺼져 있으면 큰 영상은 재생되지 않습니다.
- 폰 서버는 아직 연결 전이므로, 현재 사이트는 안전하게 100MB까지만 허용합니다.

처음에는 **같은 Wi-Fi 안에서만 시험**합니다. 바로 인터넷 전체에 공개하지 마세요.

## 준비물

1. 안 쓰는 안드로이드 폰
2. 충전기와 안정적인 Wi-Fi
3. 1TB USB와 OTG 젠더
4. 컴퓨터에 있는 이 `phone-media-server` 폴더

USB를 연결하기 전에는 안의 중요한 파일을 다른 곳에 백업해 두세요.

## 1단계: 폰에 Termux 설치

Termux는 폰에서 서버 명령을 실행하게 해 주는 앱입니다.

1. 폰에서 F-Droid를 열고 `Termux`를 설치합니다.
2. Termux를 실행합니다.
3. 아래 명령을 한 줄씩 복사해서 실행합니다.

```sh
termux-setup-storage
pkg update
pkg upgrade
pkg install nodejs nano
```

첫 번째 명령 뒤에 사진·파일 접근 허용 창이 뜨면 허용합니다.

## 2단계: 서버 폴더를 폰으로 옮기기

컴퓨터의 `phone-media-server` 폴더를 USB 케이블이나 파일 전송으로 폰의 `Download` 폴더에 옮깁니다.

Termux에서 아래 명령을 실행합니다.

```sh
cp -r ~/storage/downloads/phone-media-server ~/
cd ~/phone-media-server
npm install
cp server-config.example.json server-config.json
```

`npm install`은 서버 시작 준비가 정상인지 확인하는 과정입니다. 현재 서버는 따로 결제하거나 내려받아야 하는 부품이 없습니다.

## 3단계: USB 저장 위치 확인

USB를 폰에 연결한 뒤 Termux에서 아래 명령을 실행합니다.

```sh
ls /storage
```

`1234-ABCD`처럼 생긴 이름이 보이면 그것이 USB 주소일 가능성이 큽니다. 아래 명령의 `1234-ABCD` 부분을 실제 이름으로 바꿔서 폴더가 만들어지는지 확인합니다.

```sh
mkdir -p /storage/1234-ABCD/yangjung-media
```

만약 권한 오류가 뜨면 여기서 멈추고 오류 화면을 보내 주세요. 폰마다 USB 주소가 달라요.

## 4단계: 설정 파일 한 번만 채우기

Termux에서 아래 명령을 실행합니다.

```sh
nano server-config.json
```

처음 시험할 때는 아래 네 곳만 확인하면 됩니다.

```json
"publicBaseUrl": "http://폰의-와이파이-IP:8787",
"storagePath": "/storage/1234-ABCD/yangjung-media",
"firebaseProjectId": "yangjung-science",
"allowedOrigins": ["https://gimdong2804-pixel.github.io"]
```

`publicBaseUrl`의 폰 IP는 폰 Wi-Fi 상세 화면에서 확인할 수 있습니다. 예를 들어 `192.168.0.15`라면 `http://192.168.0.15:8787`입니다.

이 서버는 Firebase의 기존 Google 로그인 정보를 확인합니다. 그래서 Firebase의 비밀 열쇠 파일을 폰에 넣지 않습니다.

저장: `Ctrl` + `O` → Enter. 종료: `Ctrl` + `X`.

## 5단계: 폰 서버 켜기와 첫 확인

```sh
cd ~/phone-media-server
npm start
```

`[준비 완료]`이 보이면 성공입니다. 폰 브라우저에서 아래 주소를 열어 보세요.

```text
http://127.0.0.1:8787/health
```

`{"ok":true...}`처럼 보이면 폰 안의 서버는 켜진 것입니다.

## 6단계: 아직 하지 않는 것

인터넷 전체에서 접속하게 만드는 작업은 나중에 합니다. 이 단계가 성공해야 다음 단계로 갑니다.

- 먼저 200MB MP4 하나를 같은 Wi-Fi에서 업로드·재생 시험
- 그 다음 외부 공개 주소(터널) 연결
- 마지막으로 `phone-media-config.js`의 `enabled`를 `true`로 변경

공개 주소를 만들 때도 큰 영상은 8MB씩 나눠 보내도록 이미 준비되어 있습니다. 단, 무료 터널은 주소가 바뀌거나 월간 전송량 제한이 있을 수 있으니, 시험 성공 전에는 실제 동아리 영상으로 사용하지 않습니다.

## 켜 둬야 하는 것

- 폰 충전기 연결
- Wi-Fi 유지
- Termux와 서버를 강제 종료하지 않기
- 배터리 절전 기능에서 Termux 제외
- USB가 빠지지 않게 하기

이 중 하나라도 꺼지면 큰 영상 업로드나 재생이 멈춥니다.
